# New Chapter TMS Landing Page

Marketing landing page for New Chapter TMS — a psychiatrist-led clinic in Spokane, WA offering NeuroStar TMS therapy.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Conversion-focused landing page with hero, symptom checklist, who we treat, differentiation, NeuroStar credibility, testimonials, and inquiry form
- Embedded 4TMS inquiry form
- Twilio call tracking number: (509) 844-9239
- Responsive design with Tailwind CSS

## Deploy

Deploy on [Vercel](https://vercel.com) or any Next.js-compatible host:

```bash
npm run build
npm start
```
